# v3.11.23 — 修复 TexMathDelimiters 围栏内空行死循环（上游原版 bug）

## 背景

上游社区报告：`TexMathDelimiters.normalize()` 在代码块（```）内遇到空行时死循环。
本版独立复现确认属实并治本修复（该实现为上游 3.3.1 原版，本 fork 合并时原样带入）。

## 根因与修复

- **根因**：围栏内整行跳过时只更新 `index` 不同步 `lineStart`；
  空行时 `lineEnd == index`，`index = lineEnd` 原地踏步 → `while` 无限循环。
- **触发条件**：文本含 `\(` 或 `\[`（否则提前返回）+ 围栏内空行；
  生产链路 `StreamingGfmParser`（聊天 markdown 渲染）必经 → 主线程 ANR/CPU 100%。
- **修复**：围栏内跳过改为 `index = lineEnd; lineStart = lineEnd + 1`
  （空行时前进；非空行与原行为等价）。
- **验证**：独立复现测试（修复前 2s 超时卡死 → 修复后通过）+ 围栏语义用例（跳过/围栏外转义不变）+ 全量门禁非环境新增 = 0。
