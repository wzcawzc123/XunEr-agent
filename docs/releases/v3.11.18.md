# v3.11.18 — 合并上游三批（结果卡片归档回跳 + Anthropic 缓存断点）

## 背景

延续合并哲学（**重复的功能取上游做得更好的版本；我们独有的自研成果保留**），
本版合并 v3.11.17 之后的三批上游更新；上游剩余 3 个大 UI 重构域（模型选择器/角色头像/浏览器记忆页）
经评估属**架构级重构**（拆分式替换我们的自研一体实现），适合专项实施 + 真机验证清单，不在本版顺手替换。

## 修复/增强

### 1. 外部入口任务结果卡片回到对应会话（fix，`a264a31`）
- `RuntimeService`：`resultArchive` 记录外部 run 的来源+会话键；结果卡片 intent 按
  「会话 ID 直达 / 归档键导入打开 / 无则回首页」三分支处理。
- `MainActivity` + `AgentAppRoot` + `AgentAppState`：`ACTION_OPEN_ARCHIVED_CONVERSATION` 解析链路，
  `openAssistantConversation` 泛化为 `openArchivedConversation(source, key)`；找不到归档时停在当前界面，不切无关会话。

### 2. Anthropic cache_control 断点（feat，`250c024`）
- 系统提示 / 工具目录 / 最后一条消息各设 `ephemeral` 断点：跨会话复用 + 随轮前移，覆盖整个工具循环。
- 观察截图 transient 标记：断点落在截图之前保证下一轮命中；发送前清除标记（仅服务断点选择）。
- 同步 `AgentCompactionProviderTest`（system 由字符串改为 content block 数组）。

## 验证

- 三批各自编译 + 全量回归门禁：新增非环境失败 = 0（Robolectric 由 CI x86_64 全量验证）。
- 真机建议复测：① 系统助手（语音/外部入口）发起 run 后结果卡片「回到 Eta」直达对应会话；
  ② Anthropic 会话长工具链的缓存命中（`cache_read_input_tokens` 非零且比例上升）。
