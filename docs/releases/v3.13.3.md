# v3.13.3 — 记忆页编辑卡顿治本 + UIUX 精简（删热力图/去折叠/色点）

## 背景

记忆页编辑大记忆（真机 242KB/17 万字符）时每次击键全量 UTF-8 编码 + 全量字符串比较
+ 整页重组 → "删除一个字都卡、键盘都卡、保存栏弹出掉帧"。同时按反馈精简 UIUX：
热力图无人使用、概览两层折叠交互繁琐。

## 根因与修复

### A1 — 击键路径去掉全量编码（治"键盘都卡"）
- **根因**：`updateMemoryDraft` 每次击键执行 `content.toByteArray(Charsets.UTF_8).size`，
  对 242KB 全量编码（主线程 2-5ms）。
- **修复**：`draftBytes` 惰性化——击键只更新 `draft`，精确字节数在**保存时**按需计算
  （保存是低频操作）。编辑过程不再做全量编码。

### A2 — dirty 标记替代全量字符串比较
- **根因**：`hasUnsavedChanges` 用 `draft != savedContent`，每次重组对 242KB 比较。
- **修复**：`AgentMemoryUiState` 加 `dirty` 布尔，`updateMemoryDraft` 置 true、
  保存/丢弃/加载后置 false——`hasUnsavedChanges` 读布尔，O(1)。

### A3 — 保存栏动画只在 dirty 翻转时触发
- **根因**：`MemorySaveBar` 的 `AnimatedVisibility` 条件读 `hasUnsavedChanges`（每次重组
  都触发状态判断），首次出现动画叠加在整页重排上 → 掉帧。
- **修复**：条件改读 `dirty`（A2），只在 dirty 从 false→true 时动画一次。

### UIUX — 删热力图 / 去折叠 / 标题色点
- **删热力图**：`MemoryHeatmapSection` + `ConversationHeatmap` 组件 + `ConversationHeatmapLogicTest`
  （组件无其他引用，低频无人看，避免死代码）。
- **去折叠**：设置区（启用开关/注入预算）平铺显示，删除 `OverviewHeader`/`overviewExpanded`
  两层 `AnimatedVisibility` 嵌套与相关死代码（`TargetChip`）。
- **标题色点**：文档标题旁 8dp 色点一眼区分长期/短期（primary vs primaryContainer），
  辅助 "MEMORY.md（短期）" 文字。

## 验证

- 编译通过；全量门禁 365 失败**全部为 Robolectric 环境性失败**（本机 aarch64），
  非环境新增 = 0。
- 编辑卡顿的修复（A1-A3）为纯状态层改动，门禁 + CI 后需真机确认编辑流畅度。
