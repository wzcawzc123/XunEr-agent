# v3.13.2 — 记忆页：性能、布局与短期记忆引导

这一版集中在记忆板块，解决「进入卡顿」「正文被挤成一条」「短期记忆从来是空的」三个问题。

## 性能

**进入记忆页白屏半秒以上、切换长期/短期同样慢**

上游 `fab1fea`（08-03）把整个 MEMORY.md 塞进一个可滚动 Text，Compose 需要全量测量。
上游没有这么大的记忆文件，而我们的有 17 万字符。

修复：
- 预览只渲染**核心区**（`# 核心记忆` 到下一个一级标题），归档区不参与渲染
- 预览底部提示「归档区还有 XX KB · 切到编辑查看全文」
- 搜索在预览下只过滤核心区，不再 split 全文
- 编辑模式保持全文（主动进入，可接受慢）

## 布局

**正文区被上方常驻内容挤成一条，看起来像「滚动锁死」**

根因：外层 Column 不滚动，而设置卡片 + 热力图 + 搜索框常驻占位约 290dp。

重构为四段式：
1. 长期/短期切换（固定）
2. **记忆概览（新增折叠区，默认收起）** —— 展开才显示启用开关 / 注入预算 / 热力图
3. 搜索框（固定）
4. 文档卡片（唯一滚动区，空间增加 200dp+）
5. 保存栏（固定）

同批视觉修正：
- 长期/短期改用与「预览 / 编辑」**同一套分段控件**（外层 squircle 容器 + 内层选中态 + 颜色过渡）
- 「整理」按钮同款胶囊，两字，去掉图形符号
- 热力图水平/垂直占位系数统一（原来右侧空 15.6%，没铺满）
- 搜索框补上下留白，不再与文件卡片粘连

## 功能

**短期记忆从创建至今一直是空的**

`c6b49b9`（10-16）落地了 ShortMemoryRepository、独立文件、`memory_write(target="short")`、
UI 切换按钮 —— 但 `AgentPromptBuilder` 里**一个字都没提短期记忆**，模型不知道它存在。

修复：记忆系统提示补上两层区分与判断标准：
- 长期：跨会话稳定的项目事实、偏好、环境约定
- 短期：当前任务的工作草稿（中间结论、待验证假设、跨几轮才用完的临时数据）
- 判断标准：下次开新会话还需要吗？需要 → 长期；只对当前任务有用 → 短期
