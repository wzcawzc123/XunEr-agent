# v3.11.17 — 合并上游四批更新（终端修复/缓存命中/手势让路/记忆固定/聊天朗读）

## 背景

上游 Mangi-11/Eta 在 v3.11.16 之后新增 13 个提交（10-13→10-14）。按既定合并哲学
（**重复的功能取上游做得更好的版本；我们独有的自研成果保留**）分批合并，
本版包含四批独立功能（每批过编译 + 门禁）。

## 修复/增强

### 1. 终端输入管道修复（fix）
`ShellProcessSupervisor`：stdin 写入 IOException 防护——子进程提前退出/校验失败关闭读端时，
不再让写线程异常终止 Runtime；声称成功但输入未完整传输时返回 `SHELL_STDIN_FAILED_EXIT_CODE(-4)`，
`ShellFileToolBackend` 映射为 `FILE_INPUT_FAILED`（提示重新读取确认文件状态）。

### 2. Provider 缓存命中（逻辑修复）
- **工具目录作为请求前缀只增不减**（`AgentModelClient.publishedTools`）：Root 授权真正变化才整体重建；
  短暂不可用的工具仍保留（执行时自行报告错误码），避免一次瞬时能力抖动废掉整段缓存。
- **记忆上下文按会话固定**（`ConversationMemoryPins` 新，LRU 32 + revision 乐观校验）：
  系统提示多轮逐字节不变，本会话 `memory_write` 成功记录 revision 不重建；外部编辑/上下文压缩/窗口变化/运行失败时重新注入。
- 用量补读（OpenAi `cached_tokens` 等）与系统提示 Root 稳定化经核查我们已实现，无需移植。

### 3. Agent 手势经过状态胶囊自动让路（feat）
`AgentOverlayClearance`（新）：胶囊可触摸窗口会截走无障碍注入手势与 Root input 事件——
手势与胶囊相交时先置窗口不可触摸并淡出（仅绘制层），手势完成后延迟恢复（去抖防闪动）。
接线：RuntimeService 提供 Host（触摸包围盒 + 边缘余量）、胶囊 `yielded` 动画、tap/tapArea/swipe 手势包裹
（element/longPress 手势后续批次补）。

### 4. 聊天自动朗读（feat）
- `ReadAloudPlaybackService`（新，Manifest 注册 `mediaPlayback` 前台服务）：出声期间保活，退后台/锁屏继续朗读。
- `StreamingSpeechSynthesis`（新）：整篇单会话流式合成；出声前失败回落逐段请求，已出声不重读。
- `DoubaoTtsCodec`（新）：豆包 TTS 编解码。
- `SpeechPlaybackController` + `SpeechAudioLease`：`interruptOnScreenOff`（朗读锁屏不打断，录音/浮窗保持原行为）+ 流式播放逻辑。
