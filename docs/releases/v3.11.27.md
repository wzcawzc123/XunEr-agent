# v3.11.27 — 记忆升级：短期分层 / rollup 整理 / 记忆中心 UI 增强 / 会话热力图

## 背景

按 `docs/specs/memory-upgrade.md`（v2 完整落地方案）一次性落地四个小机制：
不引入 embedding/向量库、不移植 mem0 结构化、记忆不移出 system prompt
（深挖确认 OmniBot 的 "mem0" 是空壳——Kotlin 侧零实现，真实后端是 Markdown 行条目）。

## 机制与实现

### 4.1 存储层：短期记忆分层
- 新增 `ShortMemoryRepository`：独立文件 `filesDir/memory-short/memory/MEMORY.md`，
  与长期完全隔离（清空短期不影响长期）；复用 `AgentMemoryStore`（revision 乐观锁 /
  AtomicFile / 1 MiB / 3500 字符单写，参数化已有先例——角色记忆同款模式）。
- `MemoryRepository` 统一接口：长期/短期仓库可互换路由。
- `memory_get` / `memory_write` 增加 `target` 参数（enum long|short，**默认 long 向后兼容**）；
  `MemoryPageKey` 含 target（long/short 各自独立防重复页误判）。

### 4.2 会话热力图
- 新增 `ConversationHeatmap` 组件（GitHub 风格 16 周网格、按天计会话数、0-4 强度分桶、
  连续天数 streak——照 OmniBot ConversationHeatmap 逻辑），挂在记忆页设置区下方。
- 数据源：会话表 `updatedAt` 按天聚合（`AgentConversationStore.load`），只读、异步加载。

### 4.3 记忆中心 UI 增强
- **long/short 切换**：记忆页顶部 chips（长期记忆 / 短期记忆），切换丢弃未保存草稿并重载对应仓库。
- **搜索过滤**：预览模式下按关键词过滤（命中行保留、其余折叠为省略号），只过滤展示不落盘。

### 4.4 rollup 整理（手动触发）
- 新增 `MemoryRollup`：读短期 store → LLM 提炼成 Markdown 小节候选 → 追加到长期 store。
- 失败安全：LLM 失败/输出无效/`(无)` 判定均不写任何文件；追加走 revision 乐观锁，
  冲突则放弃本次不覆盖并发写入。
- UI：短期模式下"整理到长期"按钮，完成后自动刷新；短期记忆**不进核心注入**
  （防 `ConversationMemoryPins` 缓存击穿），核心注入逻辑零改动。

## 验证

- 新增测试：`MemoryRollupTest`（5 用例：空短期不调 LLM / 追加成功 / 无候选不动长期 /
  LLM 失败双保留 / 冲突不覆盖并发——内存假仓库不依赖 AtomicFile，本机执行）、
  `ConversationHeatmapLogicTest`（2 用例：周网格构建/streak，本机执行）、
  `AgentMemoryStoreTest` 新增 long/short 隔离用例（Robolectric，CI 执行）。
- 全量门禁：365 失败**全部为 Robolectric 环境性失败**（本机 aarch64），非环境新增 = 0；
  新增 Robolectric 测试由 CI x86_64 执行验证。
