# v3.13.7 — 记忆搜索「没反应」修复：全文定位 + 编辑死区 + 空命中反馈

## 背景

真机反馈：记忆页搜索框输入「核心」等关键词，正文没反应。

## 根因

搜索功能只完成了半套：

1. **编辑模式是死区**：`searchQuery` 只被 `MemoryPreview` 消费，`MemoryEditor`（编辑区）
   完全不接收 —— 编辑模式下输入关键词，正文零变化。
2. **预览只搜核心区切片**：预览渲染的是「# 核心记忆」到下一个一级标题之间的核心区
   （默认 32K 预算），`filterLines(slice.text, query)` 只在这段里找 —— 242KB 全文的
   归档区内容永远搜不到。
3. **空命中零反馈**：`filterLines` 无命中时返回空串 → 预览区整页空白，用户分不清
   「没搜到」还是「没生效」。
4. 顺带发现 `filteredDraft()` 是定义了从未被调用的死代码，暴露了搜索设计的半成品状态。

## 修复

- **预览搜索全文**：`display` 计算从 `slice.text` 改为全文 `content`（归档区也能定位命中）；
  无搜索词时仍渲染核心区切片（保持防全量布局白屏的设计）。命中行数量少，渲染量小。
- **编辑模式输入搜索词自动切预览**：编辑区是输入框不能过滤正文，输入非空搜索词时
  自动切到预览展示命中结果（草稿保留、dirty 不变，可切回继续编辑）。
- **空命中提示**：搜索无命中时显示「未找到包含「xx」的内容 · 试试其他关键词」，
  不再整页空白。
- 删除死代码 `filteredDraft()`。

## 验证

- 编译通过；全量门禁 365 失败全部为环境性（363 Robolectric aarch64 + 2 DexKit 基线），
  新增非环境失败 = 0。
- 真机路径：预览搜归档区关键词应能命中；编辑模式输入搜索词应自动切预览；
  无命中关键词应看到提示而非空白。
