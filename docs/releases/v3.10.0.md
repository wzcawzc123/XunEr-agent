## 上游带来什么

- **GUI 工具增强**：`type_text` 合并文本输入（可直接写入指定输入框并提交）、`scroll` 支持小幅滚动、
  `ui_nodes` 补充勾选/选中状态与输入框提示、**成功的 GUI 动作在结果里附带动作后的新界面**（`after` 字段）。
- **坐标契约变更**：坐标工具必须显式声明 `coordinate_space`；看截图定位用 `normalized`（0–999，不受模型侧图片缩放影响），
  坐标来自 `ui_nodes` 用 `screen`。
- **运行浮层重构**：`orb`/`bubble` 合并为 `capsule` 胶囊 + 边缘流光；结果卡片可回到 Eta 并定位到本次会话；
  状态栏胶囊显示模型思考；新增 `AgentOverlayCapsule` 等组件。
- **CI**：标签与 versionName 一致性校验、Release 草稿 job。
