# v3.13.0 — 自动任务 + 计划模式（真机验收版）

新增「自动任务」：让 Agent 在你离开后按时间/条件自己跑一轮，结果回到原会话。
同时把「计划模式」推到真机可用，并修掉一批只有真机才能发现的问题。

## 新功能

### 自动任务

在对话里直接说「帮我盯 CI」「有结果告诉我」，模型会建一条任务，
之后由 **root 守护脚本** 轮询触发：

```
守护脚本（root、setsid 独立会话）
  · 每 60 秒读 /sys 判断充电 / 亮屏 / WiFi
  · 读 App 导出的 pending.txt 判断是否到点
  · 命中 → am startservice 唤醒 App
        ↓
App 在当前会话**发起一轮正常对话**（等价你发了一条消息）
        ↓
结果落库 + 界面实时刷新 + 通知
```

- **时间语义**：`after`（延迟一次）/ `every`（固定间隔）/ `daily`（每天某点）/ `none`（只看条件）
- **触发条件**：充电 / WiFi / 灭屏（Android 特有，桌面端不需要）
- **投递方式对齐 DeepSeek Harness 的 `agent.followup`**：投进会话走正常流程，
  而不是绕过会话自己跑一次模型调用
- **忙碌时排队**：正在对话时到点不会打断，等这一轮结束再投递
- **安全网**：`max_runs`（默认 6）—— 模型忘记删任务时到次数自动停，避免整夜烧 token
- 工具：`create_auto_task` / `list_auto_tasks` / `delete_auto_task`

### 计划模式

- 进度条显示在输入框上方：收起时一行（`1/3` + 进度线 + 当前步骤），点击展开完整清单
- 展开向上撑开（消息区压缩，输入框不动），高度受限并可滚动
- 全部完成后自动消失
- 清单持久化在 `conversation_todos`，跨轮次、跨重启都在

## 真机修复（13 项）

**自动任务（12）**

1. Service 在主线程访问 Room → 整个流程静默失败
2. `schedule` 字段未持久化 → 所有时间语义失效（next 恒为 0）
3. `schedule == null` 的语义在三处写反 → 一次性任务永不结束
4. `Every` 首次立即触发 → 建完任务瞬间就跑一轮
5. busybox `[ -lt ]` 是 32 位 → 13 位毫秒时间戳溢出，时间判定全错
6. `isDue` 首次判断失效 → 任务永不执行
7. VPN 下 `activeNetwork` 是 tun0 → WiFi 条件永不满足
8. `runnableBlocking` 的 SQL 用 `last_run_at IS NULL` → 重复任务只跑一次
9. 投递用 `complete()` 旁路 → 结果进不了 UI，界面看不到
10. 删除任务不清理排队队列 → 删完还会冒出「幽灵自动轮」
11. 离线执行读 `conversations.history_json`（实际是 `[]`）→ 模型零上下文、缓存全废
12. 离线路径 60k 字符截断 → 前缀与正常对话不一致，缓存击穿

**计划模式（1）**

13. `todo_write` 回执被 `AgentTraceFormatter` 兜底成「完成」→ 计划数据全丢，进度条永不显示

## 已知问题

- 自动任务依赖 root 守护脚本；未 root 设备只能走「App 在前台时的投递」路径
- 上下文压缩在真机上仍未见生效（input_tokens 无骤降），待单独定位
- 守护脚本需手动通过 `DetachedTaskSupervisor` 托管，尚未做开机自启
