# v3.11.4 — 四项收口修复（校准跨 run / 摘要结构 / XML 引导）

## ① 校准不跨 run 存活 → 未实测前用保守初值

**问题**：校准值存在内存里，而 `AgentLoop` / `AgentContextSession` / `AgentContextBudget`
每次运行都新建，因此**每次运行的第一个请求都用未校准估算**（真机实测估算高估 4.82 倍）
→ 继续大型会话时，首轮仍可能误触发硬裁剪。

**修复**：未获得实测前使用保守初值 **0.25**（由实测 1/4.82 取整）。一旦收到 usage，即被真实比例覆盖。

## ② 摘要小节结构不校验 → 缺节重试 + 降级安全

**问题**（真机取证，会话「内存管理模块-新会话」）：模型漏掉 `## 关键上下文` 整节，该节承载的
**用户偏好 / 约束 / 未决问题**随之全部消失（实测关键词命中均为 0 次）。指令已写明"不得增删小节"，
但**系统侧零校验** —— 防线缺失。

**修复**：生成后校验八节是否齐全；缺节且**缺失不超过 3 节**时带明确提示重试一次
（只缺个别节说明模型基本按格式走、可补救；缺失过半说明没按结构输出，重试无益，直接接受首版）。
**重试仍不合规即接受首版** —— 缺一节远好于让压缩失败，后者会连带熔断、后续全靠硬裁剪。

## ③ XML 引导文案

拦截 XML 粘包时给出正确 JSON 形状示例，让模型下一轮直接改对（原先只说"值不被接受"，需它自己琢磨）。

## ④ 失败 code 落库 —— **本版未做**

排查发现 `EtaDiagnosticsReport` 已输出 `args | result`，观测能力已部分存在；
DB 中 `content` 为空另属存储设计问题，改动面大于收益，故本次不做。
