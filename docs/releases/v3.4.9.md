## Eta v3.4.9

小版本：**目测坐标系统性偏差的根因修复**（用户亲眼观察点击指示器落在目标正上方 → DB 量化定位 → 打到视觉管线这一层）。

### 根因（量化实锤）

- 模型点 (250,2711)，真实位置 (267,2877)（像素分析 ground truth）；
  x/y 两轴比例 **1.068 / 1.061 一致** → 系统性缩放 0.942，非随机误差；
  2877×0.942=2710 ≈ 2711，完美吻合。
- y 偏 166px 超过按钮半高 → 指示器落在按钮正上方 = 用户目击。
- **真根因**：服务商视觉管线把图缩放到未知比例（实测约 94%），模型在缩小后的
  视图上目测像素，却按 coordinate_contract 的 scale 1:1 当作原图坐标报出
  → 系统性偏左上。模型无法自知视图缩放率，**目测路径无解**。
- 同会话对照实证：程序化像素分析一次命中真实坐标，目测五连灭。

### 改动

- `sparseTreeNote`：写入缩放警告 + 精确坐标 SOP——root screencap 落盘目标
  区域截图，python PIL 分析目标文字/按钮的像素 bbox 取中心；
- 提示词：坐标优先取 ui_nodes；树里没有的目标走像素分析，**目测两次未命中
  强制切换**，禁止继续目测重试。
