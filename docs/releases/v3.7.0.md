## Eta v3.7.0

功能版本：**诊断导出 + 坐标锚定加固**（修复方案 M3.3 + M2.2 收官，含审查修正）。

### 改动

**M3.3 结构化诊断导出（新能力）**
- 数据备份页新增「导出诊断」：一键导出近 12 个会话的工具序列（参数/结果预览）、
  system_notice 系统事件、错误码汇总——UTF-8 文本，`CreateDocument` 保存；
- **数据源 = conversations + conversation_messages 全量**（审查修正：方案原定的
  runtime_archive_runs 只存 handoff 运行，会漏掉 99% 普通 run）；
- 隐私按 M1.4 单一真源：敏感工具（AgentSensitiveToolPolicy）参数/结果**整段脱敏**，
  不导出 API Key/敏感原文；
- 口径如实：上下文事件仅含**持久化标记**（context_compaction 带 token 增量、
  model_retry、stopped、history_trimmed）；硬裁剪无持久记录，报告注明不谎报；
- 三语言（en/简/繁），表驱动测试 3 例本地绿。

**M2.2 坐标锚定收紧（减半版，防御性加固——非修复实际案例）**
- 本 run 从未 observe/locate 就用坐标点击 → `UNANCHORED_COORDINATE`（判链首、
  独立码，M3.3 导出可统计误伤）；错误自带恢复指引"先观察再点击"；
- 审查修正三处：swipe **刻意不覆盖**（连滑翻页是合法流程）；旧契约测试
  `withoutAnyObservationCoordinatesAreAllowed` 按决策翻面；
  契约测试补 observe 保住"截图坐标契约"原意；locate→tap 共享记账天然放行。

**M2.1 小尾巴**
- LOCATE_MISS 提示增加"优先改写为屏幕上实际可见的原文（按钮/标签文字）重查"。

### 验证

- 定向：CoordinateFreshnessPolicy（含翻面+优先级新例）、EtaDiagnosticsReport 3 例、
  ScreenLocator、CoordinateContract 本地全绿；全量门禁见 CI（Robolectric 类 CI 验证）。
