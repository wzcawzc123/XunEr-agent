# v3.11.26 — 稳定性批次 C3 收尾 + 低危顺手项（校准盲区/usage 遥测/重复失败熔断/volatile/死代码）

## 背景

承接批次 A（v3.11.24）与批次 B（v3.11.25），本版处理 C3（ask-first 项的
**低风险部分**）与低危顺手项。C3c（溢出不自动重放）为保留契约，不在本版。

## 根因与修复

### C3a — round-1 默认校准初值 0.25 → 0.4（缩发送盲区）
- **根因**：0.25 源自单一真机样本（估算高估 4.82 倍）；中文密集会话实际校准约 0.6-0.7，
  恢复型 run 首轮无 usage 时 gate 用 0.25×raw，需 actual≈2.4×窗口 才裁剪，留下
  `[窗口, 2.4×窗口)` 盲区：超窗裸发 → CONTEXT_OVERFLOW。
- **修复**：初值提到 0.4（仍低于中文密集实际值，盲区缩到 `[窗口, 1.6×窗口)`；
  高估模型下折算点仍远在窗口内不会误裁；一旦收到 usage 立即被实测校准覆盖）。
- **测试**：既有 `AgentContextBudgetCalibrationTest` 契约不受影响（仅断言初值 < raw）。

### C3b — usage 连续缺失发诊断事件（遥测）
- **根因**：provider 不回 usage（OpenRouter 显式不带 include_usage 等）→ inputTokens 恒 null →
  自动压缩永久停摆，只剩硬裁剪兜底，且无任何可观测信号。
- **修复**：`AgentContextSession.observeInputTokens(null)` 连续 3 轮发一次
  `AgentEvent.CompactionUnavailable`（纯诊断，UI 不改变、不每轮刷屏；收到 usage 后计数复位）。
- **测试**：`missingUsageRoundsEmitCompactionUnavailableOnce`——连续 4 轮 null 恰好发一次
  （触发当轮计数即阈值 3）；收到 usage 后复位不补发。

### L14 — GUI 重复同参失败熔断（DUPLICATE_CALL 机械护栏）
- **根因**：模型原样重发同一组注定失败的参数（缺 coordinate_space 的 tap、同 query 的
  LOCATE_MISS、脱敏占位重放）时，唯一防线是错误文案"不要原样重发"（引导可被忽略）。
- **修复**：`AgentLocalTools.execute` 统一出口按 `tool+argumentsJson` 指纹计连续失败，
  ≥3 次返回 `DUPLICATE_CALL`（附上次错误码，引导换参/重新观察/换坐标源，不要原样重发）。
- **测试**：`repeatedIdenticalFailedCallIsFusedToDuplicateCall`——同参三次失败熔断、
  换参后 streak 复位（Robolectric，CI 验证）。

### L15 — scroll/swipe 失败不递增 contentVersion
- **根因**：`contentVersion++` 无条件执行，direction 拼错等失败也递增 → 坐标被判 STALE，
  强制多一次无谓 observe。
- **修复**：仅当结果 `ok` 时递增（`it.content.isOkJson()`）。

### L19 — contentVersion 等字段加 @Volatile
- **根因**：`contentVersion`/`observedContentVersion`/`observedPackage`/`observedScreen`
  为普通字段，而 `close()` 可被另一线程的 `cancel()` 触发（与 `publishedObservation`
  AtomicReference 的并发约定不一致）。
- **修复**：四个字段加 `@Volatile`。

### L7 — 死代码清理
- 清理 `AgentContextCompactor.overflowShrinks`（声明未用）、`AgentContextBudget.RECENT_MESSAGES`
  （定义未用）及未用 import。
- 保留 `shouldCompact`/`observe`/`exceedsWindow`（**测试引用**，非死代码——清理前已核实）。

## 验证

- 新增测试：`missingUsageRoundsEmitCompactionUnavailableOnce`（本机执行）、
  `repeatedIdenticalFailedCallIsFusedToDuplicateCall`（Robolectric，CI 执行）。
- 全量门禁：363 失败**全部为 Robolectric 环境性失败**（本机 aarch64），非环境新增 = 0。
