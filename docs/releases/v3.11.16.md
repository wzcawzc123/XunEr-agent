# v3.11.16 — 合并上游 PTY 交互式 TUI 重构（选择性子集）

## 背景

对上游 Mangi-11/Eta（main，2026-10-13）与本 fork 做了全量差异评估（125 差异文件）：
上游相对我们的实质增量是**终端 PTY 交互式 TUI 重构**（14 个独有文件 + 5 个终端核心增强）；
其余板块（model/context/runtime/overlay/phone/web 等）我们已覆盖或更完善，不移植。

合并原则（用户确立，长期生效）：
**重复的功能取上游做得更好的版本；我们独有的自研成果保留。** 本版即该原则的首次执行。

## 修复/增强（选择性子集）

### 终端 TUI（上游增量，本版合并）

1. **单元格网格渲染**（`TerminalScreenBuffer`·`AnsiSgr` 换上游网格版 + `ConsoleGridLine`）：
   按单元格精确渲染，TUI 应用（nano/htop/vim）对齐、反显、光标定位、滚动正确——此前为行文本渲染，全屏应用会错位。
2. **PTY 输入帧协议**（`PtyInputFrames`）：stdin 数据帧 + 窗口尺寸帧（SIGWINCH），防止终端字节流夹带可伪造控制序列；`ConsoleSessionController` 输入帧化 + `resize()`。
3. **功能键/DECCKM 编码**（`TerminalKeyEncoder`）：方向键/Tab/功能键按当前会话光标键模式编码，TUI 程序切换后无需界面感知。
4. **App 级后台命令宿主**（`BackgroundTerminalJobs` + `DetachedTask` 扩展 + `BackgroundCommandNotification`）：
   持久后台命令跨 App 重启认领（pid+token 防错杀）、完成通知（点击直达终端）、启动自动恢复、
   `terminal_job` 工具（start/list/read/wait/stop）。
5. **控制台 UI 组件**（`ConsoleKeyBar`/`ConsoleTextInput`/`TerminalToolbar`/`TerminalPlaceholder`）：
   软键盘补齐方向键/粘贴/键盘开关；环境/会话/后台任务管理栏；`EtaFonts` 等宽字体（JetBrains Mono 随包）。
6. **核心融合**（以我们版为底，叠加增量，防回归）：
   - `RootShellTerminalController` 增 `backgroundJobs` 宿主 + `terminal_job`；保留我们的超时/缓冲上限/清理
   - `ConsoleStore` 增 `sendKey/sendText/paste/setThemeColors` + RenderLine frame + 输入单线程保序；保留租约/节流
   - `DetachedTaskSupervisor`/`ShellProcessSupervisor` 补上游 API（stopCommand/markCompletionNotified/ownershipOf）
   - 接线：`AgentLocalTools` 挂后台宿主、`EtaApp` 启动恢复、`MainActivity` 通知跳终端

### 未改动（维持 fork 自研）
- 非终端板块（模型/上下文/overlay/runtime/web/OCR/坐标策略/工具校验等）**零改动**
- 终端内我们独有的 daemon 任务 UI、TerminalToolContract、Androguard 等保留
