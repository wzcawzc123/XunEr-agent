## Eta v3.4.5

本版把上游 Mangi-11/Eta 3.1.0 的 14 次提交合入 fork，同时保住 fork 自有的
vision 开关、相机与图片多选、androguard 分析、独立聊天页、空正文纠偏等能力；
并让发布工作流首次真正跑起全量单测。

### 一、合入上游（3.1.0）

- **语音**：新增千问与豆包内置音色选择；剥离流式 WAV 文件头，消除播报开头杂音；
  预缓冲后启动语音播放，避免首包等待欠载。
- **聊天渲染**：自建 Markdown 渲染层并移除 mikepenz 依赖（组件迁至 `ui/markdown`），
  安装包体积下降约 7MB；已完成的 Markdown 块冻结、思考过程自动折叠、
  展开态在组合期同步推导；工作过程改为时间线展示并精简工具调用展示。
- **上下文**：改为按实际用量控制压缩，并新增自动压缩开关；`AgentContextBudget`
  并入 `AgentContextSession`，`compact()` 不再需要 `roundTools`。
- **设置与助手**：设置页「关于」分组重构并新增检查更新；修复浮窗拖动接管、
  统一主聊天入口；统一入口图标与弹窗圆角。
- **构建**：升级构建工具链与运行依赖，补全多语言资源并修复工具与图片相关测试。

### 二、合并时的取舍（fork 侧）

- **独立聊天路由保留**：上游 3.1.0 删除了 `AppRoute.Chat`（聊天并入首页），本版
  保留原聊天页，并补齐 `AgentAppShell` 标题分支、`route_chat` 三语资源与序列化
  测试，聊天页交互与 3.4.4 完全一致。
- **空正文纠偏移植到上游重构后的 `AgentLoop`**：只有「产生了思考却没有正文」才
  纠偏（预算 2 次，用尽后按「运行已完成但没有返回文字」收尾）；纯空响应回落上游
  `MODEL_EMPTY_RESPONSE` 失败语义，两边测试同时通过。
- **`AgentHistoryTrimmer` 增加 `usageObserved` 门控**：只有观测到真实输入用量回执
  后才允许硬裁剪历史，与上游「按实际用量控制压缩」策略一致。
- **`AgentToolRequirements.toolNames` 对齐上游口径**（含 run 注入的
  `character_memory_*`），该属性仅测试使用，无运行时影响。
- 保留 fork 的角色记忆独立图标、vision 开关动作、`AgentContextBudget` 测试与
  相机/图片多选链路。

### 三、验证

- `compileDebugKotlin`、`assembleDebug` 全部通过（`app-debug.apk` 83.3MB）。
- 单测 1221 例：本机 aarch64 环境类失败 298 例（Robolectric native runtime 不支持
  aarch64、conscrypt 缺 aarch64 库、root 下 `canWrite` 恒真），相对 3.3.0 基线
  **零条真实失败**，基线另有 15 例转绿。
- 本次发布工作流包含「运行单元测试」步骤，将在 x86_64 运行环境执行真实全量。
