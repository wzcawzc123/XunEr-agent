## Eta v3.4.6

小版本：把上下文压缩的触发线固定回 fork 一直使用的 **75%**，并让相关测试跟随阈值。

合入上游 3.1.0 后，压缩判定逻辑统一收进 `AgentContextSession`，原先写在
`AgentContextBudget` 里的 75% 常量不再被调用，实际生效的一直是上游的 85%——
也就是说 3.4.5 里压缩比你们预期的更晚触发。本版改回 75%。

### 改动

- `AgentContextSession.TRIGGER_RATIO`：`0.85` → `0.75`。为系统提示、工具 schema
  与本轮新增内容留出 25% 安全余量，减少"逼近窗口才开始压缩"带来的被动失败。
- `AgentContextRecoveryTest` 边界探针由 `764_999 / 765_000` 改为
  `674_999 / 675_000`（= contextWindow 900,000 × 0.75），断言语义不变：低于阈值
  不压缩、达到阈值恰好压缩一次。测试注释已标明跟随 `TRIGGER_RATIO`，以后调整
  比例只需改常量。

### 验证

- 上下文相关 44 例单测通过（本机 3 例 Robolectric aarch64 环境失败为已知项，
  CI x86_64 全绿）；发布工作流同样会在 x86_64 跑全量单测。

其余与 3.4.5 一致（上游 Mangi-11/Eta 3.1.0 合并版）。
