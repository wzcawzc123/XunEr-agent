# v3.11.21 — 合并上游浏览器与记忆页重做（UI 重构域收官）

## 背景

上游 13 个提交（v3.11.16 之后）的功能**全部合并完成**。本版为最后一批：
浏览器与记忆页重做（60eac0e）+ 角色身份提供层前置。

## 修复/增强

1. **AgentMemoryScreen 取上游重做版**：预览/编辑双模式、空态与丢弃交互——
   **关键审查结论**：上游 UI 的 `AgentMemoryStore` API 与 fork 完全一致，
   `AgentMemoryContext`（217 vs 上游 86）与 `AgentMemoryToolCatalog`（我们自研）
   全程保留，仅补 4 条字符串资源。
2. **AgentBrowserScreen 取上游打磨版**：地址栏/溢出菜单/状态条重构（双方各自重做，取上游更优），
   数据层 `AgentBrowserSession` 兼容未动。
3. **角色身份提供层**：首页聊天舞台 `LocalRoleplayChat`（气泡署名头前置，供 ChatMessageItem 消费）。
