# v3.11.19 — 合并上游模型选择器 sheet 双形态 + 搜索

## 背景

域 1（provider 模型选择器）专项合并第一批：上游把选择器重构为「popup 快速列表 + bottom sheet」双形态并加入搜索。
经审查，**上游没有视觉开关（vision toggle）**——该能力为 fork 自研，本版融合时完整保留。

## 修复/增强

1. **选择器双形态**：模型数 ≤8 保持原有 popup；>8 底部面板（OverlayBottomSheet）——
   InputField 搜索 + EtaChoiceChip 服务商筛选 + 分组列表 + 选中对勾停留动画（确认后再收起）。
2. **模型搜索**（`ModelSearchQuery`，新）：多词模糊匹配，`v4flash` 可命中 `DeepSeek V4.1 Flash`，服务商名参与匹配。
3. **数据层**：`modelCount`/`filterGroups` 扩展；保留我们的 `supportsVision`/`defaultExpandedModelProviderIds`。
4. **sheet 行沿用带视觉开关的 ModelPickerRow**（上游无 vision，为 fork 自研）；`AgentContextUsageButton` 保持我们版。

## 剩余深水区（下轮专项，数据层双向独有需逐段融合）

## 验证
