## Eta v3.6.0

功能版本：**locate OCR 通道 + 隐私策略单点落地**（修复方案 M1.1/M1.2/M1.3/M1.4/M2.1 收官，M2.3 顺带）。

### 改动

**locate_on_screen OCR 通道（M2.1 完结，新能力）**
- 树匹配之后新增第 2 级：ML Kit 中文离线识别（bundled 模型，**APK 约 +20MB**，不依赖 GMS）
  对截图像素直接求文字 bbox——"树里没有 ≠ 屏幕上没有"，KSU Compose 列表类场景根治；
- 行+元素双级候选复用同一评分排序；坐标常态 1:1、分辨率不一致时防御性按比例换算；
- 错误语义细分：树空且无截图 = `LOCATE_UNAVAILABLE`；树与 OCR 均未命中 = `LOCATE_MISS`。

**隐私策略单点落地（M1.4，2026-10-04 用户决策）**
- 默认敏感：当轮可见、持久形状化；**记忆与读图不再设默认豁免**（read_image 旧"功能优先"
  豁免废除）；跨会话靠记忆系统与再取数，不靠 transcript；
- `AgentSensitiveToolPolicy` 重写为四分组单一真源，权限清单改为引用派生；
- 补齐散落期欠账：`set_device_state`/`app_state_control` 此前漏挂策略表。

**上下文失败可恢复（M1.2）**
- 摘要压缩失败（`CONTEXT_NO_REDUCTION` 等）不再整 run 毙命 → 降级硬裁 → 仍超窗返回
  可恢复 `CONTEXT_EXHAUSTED`（带"新开会话"指引）；新事件 `HistoryTrimmed` 打通
  wire/浮窗/系统通知；TRIGGER 0.75 < TARGET 0.95 档位锁。

**记忆分页（M1.3）**
- 同参同 revision 分页重读 → `DUPLICATE_PAGE` 强制续读；只比对最后一页（读其他页解锁）、
  revision 进 key（写后解锁）。

**Prompt 净化（M1.1，OCR 落地后按方案时序解锁）**
- 删除"视觉管线缩小 6%/系统性偏左上/root screencap+python PIL"个案 SOP，改为
  locate → LOCATE_MISS → 目测两次停止 的短规则；测试加 assertFalse 防回潮。

**回归锁（M2.3）**
- 契约构建抽纯函数 `buildCoordinateContract` + 3 例本地锁（2K/FHD 换算、1:1、无截图不给 scale）。

### 验证

- 全量 1260 例：新增非环境失败 0（304 环境类 + 2 已知 DexKit）；
- 定向：ScreenLocator 7、CoordinateContract 3、AgentContextRecovery 13、策略表 5 例本地全绿；
- Locate/OCR 5 例与 read_image 尺寸 2 例为 Robolectric，由 CI 验证。

### 已知限制

- OCR 首次调用需加载模型（约 1-2s 冷启动，后续复用）；模型不可用时自动回落 LOCATE_MISS 语义。
- M1.4 行为变更：read_image/set_device_state/app_state_control 的参数与结果不再进持久
  transcript（当轮不受影响），旧会话中已持久的不受追溯影响。
