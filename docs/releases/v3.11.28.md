# v3.11.28 — 记忆升级终审修复（P1 文档标题区分 / P2 切换防丢草稿）

## 背景

对 v3.11.27 记忆升级做终审（核心正确性全部确认无问题：存储隔离/权限守卫/
缓存安全/超时兜底/重复页判据/向后兼容/并发防抖），发现 2 个 UX 问题，本版修复。

## 根因与修复

### P1 — 文档标题未区分长期/短期
- **根因**：`MemoryDocumentCard` 标题固定显示 "MEMORY.md"，但短期文件实际也叫
  MEMORY.md（在不同目录）——切换到短期模式时用户无法分辨当前编辑的是哪个。
- **修复**：标题按 `state.target` 区分——短期模式显示 "MEMORY.md（短期）"，
  长期保持 "MEMORY.md"。

### P2 — 切换 long/short 目标丢未保存草稿无确认
- **根因**：`switchTarget` 切换即丢弃未保存草稿（设计如此，但无确认提示），
  误触切换会直接丢编辑内容。
- **修复**：切换前若有未保存草稿（`hasUnsavedChanges` 且目标不同），弹确认框
  "丢弃并切换"；确认后才发 `SwitchTarget`，取消保留草稿。无草稿时直接切换，行为不变。
