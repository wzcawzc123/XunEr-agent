# v3.11.15 — 会话切换懒加载显示加载占位，不再闪空白聊天页

## 背景

v3.11.14 引入启动懒加载（只载选中会话，其余按需补载）后，真机反馈：**切换会话出现一次空白聊天页**，
切换过一次后不再出现，杀后台重启后复发。

根因：切换未载入会话时，`homeState` 先被置为「空消息占位」，而聊天区 UI 把空列表渲染成
空会话引导页（"我能帮你做什么"+ 建议语）——切换瞬间看到的正是这个空态页；
补载完成后该会话 `messagesLoaded=true` 常驻，再切回不闪；重启后所有会话回到未载入态，故复发。

## 修复

### 逻辑修复 / UI 增强

1. **`AgentChatBody` / `AgentChatScaffold` 新增 `messagesLoaded`**（`ui/components/AgentChatBody.kt`）：
   未载入会话显示「正在加载会话…」占位（进度圈 + 文案），并**隐藏底部输入条**（防加载窗口内误输入），
   不再闪出空会话引导页。首启（选中会话启动即载入）、已载入会话切换、新建会话（默认 `true`）行为不变。
2. **载入失败兜底**（`AgentAppState.lazyLoadConversation`）：
   补载异常时把占位标记为已载入空态 + 失败日志，避免聊天区**永久停在"加载中"**；再次切换会重新尝试。
3. **恢复/导入路径兜底**（`AgentAppState.ensureConversationLoaded`）：
   单会话载入包 try-catch，异常降级返回 null（对应入口跳过），防恢复流程崩溃。
4. 调用点传参：`AgentHomeScreen`（首页聊天主舞台）、`AgentChatScreen`（独立对话页）。

### 未改动（维持）
- 懒加载本身、保存防误删（messagesLoaded=false 跳过消息差分）、previews 列表预览——v3.11.14 逻辑全部不变。

## 验证

- 编译（主代码 + 测试代码）通过。
- 全量回归门禁：新增非环境失败 = 0（Robolectric 由 CI x86_64 全量验证）。
- 边界推演：切换未载入 → 加载占位 → 补载后正常；快速连续切换（旧加载任务取消）正常；
  失败后保存路径不误删（空消息 + messagesLoaded=true 时 diff 不触发删除）。
