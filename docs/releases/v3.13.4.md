# v3.13.4 — 用量统计完善：风格统一 + 按模型分组 + 下拉刷新

## 背景

用量统计页（v3.13.0 引入）功能已完整，但布局用裸 `miuix.Card` + 自定义排版，
与记忆页/设置页的 `EtaCard`/`EtaPreference` 体系割裂。本版统一风格并补齐三个能力缺口。

## 修复与新增

### 风格统一（消除割裂感）
- 用量页全面切换到项目标准组件：`EtaCard`（24dp 圆角）+ `EtaPreferenceGroupItem`/
  `EtaPreferenceRow`（squircle 分段、行尾数值、分割线）——与记忆页/设置页同一套视觉语言。
- 指标行数值用 `endActions`（行尾）而非 `bottomAction`（行下），对齐 `EtaPreferenceRow`
  语义（前者是行内右对齐，后者是整行下方补充区）。

### U3 按模型分组
- **根因**：总账看不出钱花在哪个模型上（不同模型单价差异大）。
- **实现**：DAO 新增 `tokenUsageByModel()`（JOIN 会话表 `conversations.model_id` 按模型分组——
  消息表无 model_id，模型归属在会话表）；`AgentCostSummary.ByModel`（`displayName` 兜底
  "未绑定模型"）+ `byModel` 列表；`AgentCostRepository.byModel()` 总账 = 各模型之和
  （与 `tokenUsageAll` 同口径），按输入降序。用量页新增「按模型分组」卡片。

### U4 下拉刷新
- miuix `PullToRefresh`。`onRefresh` 是**非 suspend** 回调，不能直接调 suspend `load()`——
  改为置 `refreshing` 标记，由 `LaunchedEffect(refreshing)` 触发加载。

### U5 测试
- `AgentCostSummaryTest` 补 `byModel` 断言：displayName 兜底、各自可计费输入、
  与 `fromRows` 同口径核对总账。

## 验证

- 编译通过；全量门禁 365 失败**全部为 Robolectric 环境性失败**（本机 aarch64），
  非环境新增 = 0；新增 byModel 断言本机执行通过。
